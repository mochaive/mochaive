### 👋 Who I am

I'm a generalist maker who takes ideas from insight to interface to shipped product.

I've spent years experimenting with how I work, think, and organize information through tools like GTD, Things 3, Tana, and Readwise. Eventually, using existing tools stopped being enough, so I started building my own.

I'm the founder of **FolioLabs**, where I'm building **Tessera**, a knowledge product designed to bring useful information back when it matters. I'm also working on **Maestro**, a minimal task manager for humans and AI agents, **Sorro**, a native Markdown workspace, and **Email** *(working title)*, a fast and minimal email client.

I also work on an Android-based AR glass application and regularly ship smaller experiments around AI, personal tools, and new interfaces.

I'm happiest when there's a blank file open and an idea worth chasing.

### 🧠 How I work

- **I build the systems I use.** Most of my products start from problems I run into myself.
- **Products over technology.** Code is a tool for getting ideas into people's hands.
- **Generalist engineering.** Product, UX, mobile, web, branding, AI, and whatever else is needed to ship.
- **Ship globally from day one.** I build with a global audience in mind from the beginning.
